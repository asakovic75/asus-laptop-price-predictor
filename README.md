# 💻 Прогнозирование цен на ноутбуки ASUS с помощью нейросетей 🤖📊

Проект представляет собой интерактивное ML-приложение (внутри *Jupyter Notebook*),  
которое прогнозирует рыночную стоимость ноутбуков **ASUS** на основе их технических характеристик ⚙️.

Цель проекта — продемонстрировать полный цикл разработки ML-решения:
сбор данных → очистка → подготовка признаков → обучение модели → создание пользовательского интерфейса.

---

## 🛠 Технологии

- 🐍 **Python**
- 🧠 **TensorFlow / Keras** — построение и обучение нейронной сети
- 📊 **Scikit-learn** — масштабирование и кодирование признаков
- 🎛 **IPyWidgets** — реализация интерактивного интерфейса
- 📁 **Pandas / Openpyxl** — обработка и хранение данных

---

## 📊 Датасет

Для обучения модели был собран собственный датасет.

- 🔎 Источник данных: **парсинг сайта Shop.by**
- 💻 Объём выборки: **100 моделей ноутбуков ASUS**
- 📋 Для каждой модели собраны:
  - технические характеристики
  - конфигурация железа
  - актуальная рыночная цена
- 🧹 Проведена очистка данных
- 🔄 Категориальные признаки закодированы
- 📈 Числовые признаки масштабированы

Таким образом, модель обучается на реальных рыночных данных, что повышает практическую ценность проекта.

---

## 🧠 Архитектура модели

Используется **полносвязная нейронная сеть (Fully Connected Neural Network)**  
для задачи регрессии (предсказание цены).

Особенности модели:

- Несколько Dense-слоёв
- **Dropout-слои** для снижения переобучения 🎯
- Функция потерь — регрессия (MSE)
- Оптимизатор — Adam

Модель обучена на подготовленных данных и используется для предсказания стоимости в реальном времени.

## 🖥 Интерфейс приложения

Интерфейс реализован с использованием `IPyWidgets` и разделён на логические блоки для удобства пользователя.

### 🔹 Структура интерфейса

#### 📌 1. Основное
- Тип устройства  
- Линейка ноутбука  
- Операционная система  
- Год выпуска  

#### 🖥 2. Экран
- Диагональ  
- Разрешение  
- Тип матрицы (IPS / OLED)  
- Частота обновления  

#### 🚀 3. Процессор
- Модель процессора  
- Количество ядер  
- Тактовая частота  

#### 💾 4. Память
- Видеокарта  
- Объём оперативной памяти  
- Тип накопителя (SSD / HDD)  
- Объём накопителя  

В нижней части интерфейса расположена кнопка:

### 🔘 **«Узнать стоимость»**

После нажатия происходит:

- автоматическая предобработка введённых данных  
- масштабирование признаков  
- передача параметров в нейронную сеть  
- вывод прогнозируемой рыночной стоимости
