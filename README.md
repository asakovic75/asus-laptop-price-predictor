# 💻 Прогнозирование цен на ноутбуки ASUS с помощью нейросетей 🤖📊

Данный проект представляет собой веб-приложение (внутри *Jupyter Notebook*), которое предсказывает рыночную стоимость ноутбуков **ASUS** на основе их технических характеристик ⚙️.

---

## 🛠 Технологии

- 🐍 **Python**
- 🧠 **TensorFlow / Keras** — построение и обучение нейронной сети
- 📊 **Scikit-learn** — предобработка данных
- 🎛 **IPyWidgets** — создание интерактивного интерфейса
- 📁 **Pandas / Openpyxl** — обработка и хранение данных

---

## 🔍 Описание модели

Модель использует **полносвязную нейронную сеть (Fully Connected Neural Network)**  
с добавлением **Dropout-слоёв** для предотвращения переобучения 🎯.

Обучение проводится на базе данных актуальных моделей ноутбуков **ASUS**,  
что позволяет учитывать реальные рыночные характеристики и формировать корректный прогноз стоимости 💰.

---

## 🚀 Функциональность

- ✅ Ввод технических характеристик ноутбука  
- ✅ Предобработка данных в реальном времени  
- ✅ Прогнозирование цены с помощью обученной модели  
- ✅ Удобный интерактивный интерфейс
